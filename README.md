# Jewel Case

셰이더만으로 그린 투명 CD 주얼 케이스. 모델 파일도 이미지 에셋도 없이, three.js(WebGL 2)와 직접 쓴 GLSL로 만들었습니다.

```bash
npm install
npm run dev
```

케이스를 누르면 열리고, 끌면 돌아갑니다. 아래 독에서 디스크를 고르고, `S` 디스크 회전, `O` 열기/닫기, `space` 자동 재생, `←` `→` 디스크 넘기기.

## 어떻게 그리나

한 프레임은 뒤에서 앞으로 겹겹이 그려집니다.

1. **종이와 디스크** — 흰 바닥과 그 위 그림자, 디스크. 그림자는 조명에서 렌더하지 않고, 바닥의 한 점에서 조명 쪽으로 쏜 광선이 트레이·디스크·뚜껑 평면과 만나는 자리를 3×3 행렬 하나로 구해 윤곽만 검사합니다 (`gl/page.js`).
2. **투명 레이어** — 트레이와 뚜껑을 먼 것부터, 그때까지의 그림을 복사한 위에 그립니다. 그래야 로드가 자기 뒤의 그림을 굴절시킬 수 있습니다 (`stage.js`의 `draw`).
3. **글린트** — 그림의 알파에 실어 둔 핀 조명 세기에서 봉우리만 골라 십자 별빛으로 늘입니다 (`gl/post.js`).

### 플라스틱 (`gl/plastic.js`)

두꺼운 부분은 전부 "둥근 사각 단면을 경로를 따라 쓸어 만든 로드"입니다 (`geometry.js`, `case.js`). 각 정점이 자기 로드의 중심선·가로축·단면 크기를 들고 있어서, 프래그먼트 셰이더가 픽셀의 광선을 단면 안으로 굴절시켜 벽에서 벽으로 따라갑니다. 벽마다 프레넬 비율만큼 빠져나간 빛이 스튜디오를 보고, 시선에서 몇 도 안 벗어난 광선만 뒤의 그림을 봅니다.

- 단면(둥근 사각형)은 상자 둘과 모서리 원 넷의 합집합으로 보고, "안에서 출발한 광선은 마지막으로 지나는 조각에서 전체를 떠난다"는 성질로 출구를 구합니다.
- 블러는 화면 미분에 맡기지 않습니다. 얇은 로드는 삼각형이 픽셀보다 작아 미분이 잡음이 되기 때문에, 로드를 가로질러 반 픽셀 떨어진 광선 두 개를 나란히 추적해 둘이 벌어진 만큼을 블러로 씁니다.

### 스튜디오 (`gl/studio.js`)

텍스처가 없습니다. 조명은 전부 가장자리가 부드러운 막대·카드이고, 모든 조회가 블러 폭을 받아 그 가장자리를 넓힙니다(상자를 정확히 블러한 것과 같아서 작은 조명이 렌즈 너머에서도 깜빡이지 않고 에너지도 보존됩니다). 케이스 뒤쪽 벽에는 검은 고리와 빛나는 고리를 걸어 두었는데, 로드가 렌즈라서 폭 방향으로 이 고리들을 훑으며 크롬 같은 줄무늬가 됩니다.

### 디스크 (`gl/disc.js`)

트랙은 1.6µm 간격의 회절격자입니다. 격자 방정식 그대로, 조명마다 자기를 거울 반사하는 반지름 하나를 스펙트럼 색으로 밝힙니다. 앞면은 네 종류(인쇄 CD, 검은 CD, 금, 바이닐), 뒷면은 모두 은색 데이터면입니다. 디스크 그림은 로드할 때 2D 캔버스로 그립니다 (`art/`).
