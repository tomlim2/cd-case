# 오늘의 디스크

날마다 한 장씩 구워지는 가짜 음반. 시드 하나로 커버·디스크·수록곡·속지가 만들어지고, 제목과 이미지를 넣어 내 앨범으로 바꿀 수 있다.
투명 주얼 케이스는 모델 파일 없이 three.js(WebGL 2)와 직접 쓴 GLSL로 그렸다.

https://tomlim2.github.io/cd-case/

구조, 그리는 방법, 배포까지 전체 설명은 [MAP.md](MAP.md).

## 쓰는 법

- 케이스를 누르면 열리고, 끌면 돌아간다. 놓으면 앞면이나 뒷면 중 가까운 쪽으로 선다
- **다른 디스크**: 아무 시드로. 왼쪽 위 `‹ ›` 는 하루 전·뒤의 디스크
- **꾸미기**: 제목·아티스트·수록곡·디스크 재질을 바꾸고, 이미지를 넣으면 커버가 된다 (창에 끌어다 놓아도 됨)
- **링크 복사**: 시드와 적어 넣은 글이 주소에 담긴다. 올린 이미지는 브라우저 밖으로 나가지 않아서 링크에는 없다
- **PNG로 저장**: 지금 화면 그대로
- 단축키: `O` 열기/닫기, `F` 뒤집기, `R` 다른 디스크, `E` 꾸미기, `←` `→` 하루 전·뒤

## 개발

```bash
npm install
npm run dev
```

## 배포

```bash
npm version patch   # minor / major 도 됨
```

버전을 올리면 `v*` 태그가 push 되고, 그 태그가 GitHub Actions 로 Pages 에 올린다.

## 참고

투명 케이스를 그리는 방식은 [bubbbly.com/cd-case](https://www.bubbbly.com/cd-case)가 어떻게 동작하는지 살펴본 데서 출발했다. 코드는 새로 썼고, 케이스 치수는 그 화면을 재서 잡았다.
